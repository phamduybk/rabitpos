# Rabit POS — Synology DSM 7 packages

Free point-of-sale and store management that runs entirely on your NAS (DSM 7.0-40000 or later).

| File | For |
|---|---|
| `rabitpos-5.1.1-26092923-x86_64.spk` | Intel / AMD NAS (x86_64) |
| `rabitpos-5.1.1-26092923-armv8.spk` | ARM 64-bit NAS (armv8) |

Install: Package Center → Manual Install → choose the file for your NAS, then open `http://<NAS-address>:8888/`.

Or add the package source `https://rabitpos.com/synology/` in Package Center → Settings → Package Sources to get updates automatically.

Website: https://rabitpos.com · Support: admin@rabitpos.com
